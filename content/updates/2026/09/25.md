## Improvements

### Followers and following

- Follower and following lists can be searched on the server. The search matches username or display name, and it runs before paging, alongside the block, first-year and active-account filters, so results page through every match and follow the same visibility rules. (`2d30240`)
- Followers and following now open in one tabbed modal with a search box and a spinner instead of a skeleton. Switching tabs replaces the `?tab=` entry, so Back still closes the list in one step. (`0718934`)

### Shared buttons, floating nav and sheets

- One action-button style (primary, danger, secondary) is used by the confirm, report, OTP and device dialogs, with hover, pressed, focus and disabled states in both themes.
- The mobile bottom nav floats as a rounded frosted-glass bar. Page padding, the Messages composer, toasts and the match button now clear it.
- Bottom sheets can be dragged down to dismiss on phones (confirm, report and verified sheets). The verified welcome is now a scroll-locked bottom sheet.

(`6149c64`)

### Messages

- New Message is rebuilt as a picker with a recent strip, a selectable list, a sticky Chat / Create group bar and a group-name step with validation. It is a bottom sheet with drag-to-dismiss on phones.
- The inbox has a "Your messages" empty state with a Start a conversation button.
- On phones, the Messages title, search and new-message button sit exactly where Crew's do.

(`4adbbb6`)

### Lighter surfaces

Fields, cards, header buttons, the search bar, menus and drawer boxes are borderless. Menu text and icons are larger, Save Interests has a sticky bar, and the post composer's expand is lighter and no longer collapses mid-scroll on phones. (`f9c5a56`)
