## Improvements

### Follower and following search

`GET /users/:username/followers` and `/following` accept an optional `search` query that matches username or display name. It uses `ILIKE` with escaped wildcards and a 64-character cap, and is applied in SQL before `LIMIT`/`OFFSET` alongside the block, first-year and active-account filters. Results page through every match and follow the same visibility rules as the unfiltered list. (`2d30240`)

On the profile, followers and following share one tabbed modal with a server-backed search box and a spinner instead of the skeleton. Switching tabs replaces the `?tab=` entry, so Back still closes the list in one step. (`0718934`)

### Shared buttons, floating nav and drag-to-dismiss sheets

- One `.action-btn` style (primary, danger, secondary) covers confirm, report, OTP and device dialogs, with hover, pressed, focus and disabled states in both themes.
- The mobile bottom nav is a rounded frosted-glass bar. Page padding, the Messages composer, toasts and the match button now clear it.
- `useSheetDrag` is a dependency-free drag-down-to-dismiss for bottom sheets, with batched transforms, scroll yielding and flick detection. The confirm, report and verified sheets use it.
- The verified welcome is a scroll-locked bottom sheet on phones, and the verification dialog loses its borders.

(`6149c64`)

### New message sheet and inbox

- New Message is rebuilt as a picker with a recent strip, a selectable list, a sticky Chat / Create group bar and a group-name step with validation. It is a drag-to-dismiss bottom sheet on phones.
- The inbox has a "Your messages" empty state with a Start a conversation button, and shows one invitation at a time when the chat pane sits beside the list.
- On phones, the Messages title, search and new-message button sit where Crew's do, and both searches are borderless.

(`4adbbb6`)

### Borderless fields and lighter composer

Settings fields and save buttons, a sticky Save Interests bar, the verification review card, header buttons, the search bar, menus, the profile empty state and drawer boxes lose their borders. Menu text and icons are larger, and the post composer expand is lighter and no longer collapses mid-scroll on phones. (`f9c5a56`)
