## Fixes

### Security

- **SSRF in link previews:** IPv4-mapped IPv6 addresses written in hex (for example `[::ffff:a9fe:a9fe]`, the cloud metadata address) were treated as public. Private-address checks now use a `net.BlockList` that applies the IPv4 rules in every notation. (`035417c`)
- **Group membership:** add, remove and leave accepted any conversation id. A DM's creator could remove the other person or add a third, Instant Match chats could get extra members, and a removed member could add themselves back or demote an owner. These routes are now group-only, and add requires an active requester. (`9ead980`) The DM list now reports `isMember` from the viewer's own membership. (`64f52c6`)
- **Socket payloads:** the last eight realtime events now validate their payloads, and a malformed one gets an error ack instead of being processed. (`a028c89`)
- **Production config:** production refuses to boot with CSP or HSTS switched off. (`32ed551`)
- **CORS patterns:** every regex metacharacter in configured origin patterns is escaped. (`053e366`)
- **Input types:** query-string cursors and search terms are checked to be strings where they are parsed (`cf828ad`), and a non-string `adminNotes` on a verification decision is refused. (`c58e320`)
- **URL checks:** external media hosts (`880ce5e`) and DiceBear avatars (`91135d4`) are recognised by hostname, not by substring.
- **Text:** entities are decoded once in `htmlToPlainText`, so text typed as `&lt;b&gt;` no longer turns into a tag. (`3b1845b`) Backslashes are escaped in the message selector fallback. (`96ea47f`)

### Request validation

- Group settings bodies are validated with a DTO. (`f83301a`)
- Admin college routes only accept known fields and a valid status. (`9296fec`)
- Unknown enum filters on the admin report and user lists return 400 instead of 500. (`dd6fdd6`)
- Profile and settings writes check each field they read, and follower search ignores a repeated `?search=`. (`c026af6`)

### Bugs

- Uploaded media rows now store the real size and type from R2. (`def8e66`)
- Moderators no longer get a 500 on a comment page that contains a deleted comment. (`7cb1f8f`)
- Editing a community without a cover no longer fails with a 500, and the community list supports search. (`c700b38`)
- Deleted attendees are shown as deleted on the first page of an activity. (`2e187a8`)
- Directory search keeps filtering past the first page. (`54717b0`)
- The email worker no longer crashes when no Resend key is configured. (`ba1010f`)

- **Lint is blocking:** the suppressions ledger for the ~8,000-violation backlog is empty and retired. CI now runs lint with zero warnings allowed. (`1625ff7`, `70ad42c`)
- **Strict typing:** `strictPropertyInitialization` is on, with byte-identical JavaScript output. (`8f6de60`)
- **Scripts:** the verification-media, orphan-reclaim, R2 audit and preset-media scripts are TypeScript now (`6f7c781`, `c9b1d13`), and the dead monitoring seed script is deleted. (`fefd021`)
- **Queues:** BullMQ's unused `createClient` option is removed. (`25eeadb`)

- **Deploys:** deploys now run only for a commit whose CI passed. (`0569bdf`)
