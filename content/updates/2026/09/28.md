## Fixes

### SSRF bypass in link previews

The WHATWG URL parser writes an IPv4-mapped IPv6 literal in hex, so `http://[::ffff:169.254.169.254]/` has the hostname `[::ffff:a9fe:a9fe]`. `normalizeAddress` recognised only the dotted form, so the hex form matched none of the private prefixes and was treated as public. An IP-literal host skips DNS, so the pinned lookup never ran and the request could reach the cloud metadata address. Hex mapped literals are now refused. (`035417c`)

### Direct messages could be managed as groups

`POST|DELETE /:id/members` and `POST /:id/leave`, on both `/api/messages` and `/api/group-chats`, resolved any conversation id and checked only a role. The creator of a DM is its owner, so:

- A DM's creator could remove the other person, or add a third person to a private thread.
- An Instant Match chat (anonymous, 24 hours) could be given extra members.

Add, remove and leave are now group-only, and adding is made safe. (`9ead980`) The DM list also returned the literal `isMember: true` because the viewer's own `leftAt` was never selected. It now reports the real value, matching how history and `lookupExistingDM` already treat such threads. (`64f52c6`)

### Wrong data served or written

- **Upload size and type:** `confirmUpload` re-reads the object and corrects the row, but the R2 provider returned S3's raw `ContentLength`/`ContentType`, so on R2 the correction never ran and every row kept the client's declared values. `getMetadata` now returns one shape for every backend. (`def8e66`)
- **Moderator comment pages:** A deleted comment with live replies survives as a tombstone with `authorId: null`. The page asked the authorizer about every row, and Prisma rejects a null inside `userId: { in: [...] }`, so the page answered 500 for moderators in any thread of that shape. Only live comments are asked now. (`7cb1f8f`)
- **Deleted attendees on activity pages:** The detail query's member select had neither `accountStatus` nor `deletedAt`, so deleted or pending-deletion attendees on the first page were shown under their real name and photo. The select includes them and the type requires them. (`2e187a8`)
- **Directory search past page one:** `getDirectory` spread the search clause and the keyset cursor into one `where`, and both are `OR`s, so the cursor's replaced the search's. Every page after the first ignored the search text. The search now sits under `AND`. (`54717b0`)
- **Community edits without a cover:** `updateCommunity` mixed a checked update (`avatarMedia: { connect }`) with an unchecked one (`coverMediaId: null`), which Prisma rejects. Saving an edit to a community with no cover failed. (`c700b38`)
- **Follower search:** A repeated `?search=` arrives as an array and made `search?.trim()` throw a 500. Only a single string is used now. The follower and communities search from the previous days is included in these commits. (`c026af6`, `c700b38`)
- **Double-decoded text:** `htmlToPlainText` decoded entities one replace at a time, so text typed as `&lt;b&gt;` came out as `<b>`. The six entities are decoded in one pass. (`3b1845b`)
- **Resend client crash:** `EmailProcessor` built a Resend client unconditionally, and the SDK throws on an empty key. Any environment sending over SMTP alone, CI included, crashed. It passed locally only because the SDK falls back to an environment variable. The client is now built only when a key is configured. (`ba1010f`, `e3926dd`)
- **Android Gradle path:** `capacitor.settings.gradle` pointed at a path that exists only in the worktree it was generated in, so Gradle could not find the Capacitor plugins from an ordinary checkout. (`61f7c1f`)

### Validation gaps

- **Group settings bodies:** Both `PATCH …/:id/settings` routes took `@Body() body: any`, which skips the global `ValidationPipe`. They now take `UpdateGroupSettingsDto`, so an unknown field or wrong type is a 400. Every payload found in the frontend history still passes. (`f83301a`)
- **Admin colleges:** `PATCH /admin/colleges/:id` spread its body into `prisma.college.update`, so any column an admin request named was written. Create and update DTOs now name the settable fields and refuse `id`, `deletedAt`, `isVerified` and timestamps. A bad status value was a 500. (`9296fec`)
- **Admin report and user lists:** An unknown `status`, `priority`, `targetType` or `accountStatus` filter was a Prisma validation error and a 500. A shared `parseEnumFilter` turns it into a 400 naming the valid values. (`dd6fdd6`)
- **Verification notes:** A JSON array or object sent as `adminNotes` reached the service and failed in Prisma. Anything but a string is now a 400. (`c58e320`)
- **Profile and settings writes:** `PATCH /api/users/me` and `/me/settings` stay open records, since installed apps send whole form objects, but their sources and writes are typed. (`c026af6`)
- **Socket payloads:** The last eight socket events (`message:catchup`, post, activity and community joins and leaves, `conversation:join_rooms`) declared a payload that checked nothing at runtime. Each now takes `unknown` and parses it. Tracing showed they failed closed before, so nothing leaked. (`a028c89`)
- **Cursors and search:** Express turns `?cursor=a&cursor=b` into an array, and several sites call string methods on it. Not reachable today because the global pipe stringifies query parameters, but the services now check. (`cf828ad`)

### CodeQL alerts

- **Origin patterns:** `main.ts` and `socket-cors.ts` built a `RegExp` from a CORS pattern escaping only `.`, so `a+b` matched `aab`. Both use one `originMatchesPattern` that escapes everything except `*`. (`053e366`)
- **External media hosts:** `extractStorageKey` recognised Unsplash, Giphy and similar hosts by substring, so an own object such as `avatars/giphy.com-export.webp` was never cleaned up. Hosts are matched on the hostname. (`880ce5e`)
- **DiceBear avatars:** Four sites decided "is this a DiceBear avatar" by substring, and one appended a parameter to someone else's URL. `isDicebearUrl` parses the URL and compares the hostname. (`91135d4`)
- **Message selector:** The fallback for `findMessageEl` escaped `"` but not `\`, so an id ending in a backslash made `querySelector` throw. Ids are server UUIDs or client temp ids, so this is robustness, not an exploit. (`96ea47f`)
- **Production safety switches:** Production now refuses to boot with `CSP_ENABLED` or `HSTS_ENABLED` set to false, the same as `COOKIE_SECURE`. Production sets neither, so it boots unchanged. (`32ed551`)

## Improvements

### Mobile app

- **Breathing splash:** Measured on a physical phone over three cold launches, the splash took about 430 ms to leave after the page was ready, and the opening screen only began its entrance once the fade had finished, leaving about 300 ms of bare background. The logo now breathes in a seamless loop and the splash crossfades into the app. (`49c77a8`)
- **Profile cover:** The cover scrolls into a blurred header instead of being squashed, its height follows the status-bar inset, and a pull fills the gap above it. (`075afe8`)

### Deploy gating

Deploy — Development and Deploy — Production started from the same push as CI and never waited for it, so a commit whose tests failed was still built, migrated and rolled out. That happened on development at the merge. Both workflows now start with an `await-ci` job that waits for the commit's `validate` check runs, and the deploy proceeds only if they pass. (`0569bdf`, `52ff6a4`)

### Queues

BullMQ's `createClient` option, with its retry strategy and reconnect handling, is a Bull v3 option that `bullmq` 5 never reads, so none of it ever ran. It is removed. Queues connect from `connection` alone with BullMQ's default reconnect. (`25eeadb`)

## Build & Tooling

- **Lint ledger retired:** The suppressions ledger recorded about 8,000 violations. It is empty, so the file goes, CI runs `npm run lint -- --max-warnings 0`, and the README says no suppressions of any kind. (`1625ff7`) The CI header comment is corrected to match the job. (`70ad42c`)
- **Strict property initialization:** `strictPropertyInitialization` is on. The emitted JavaScript is byte-identical across all 310 files. (`8f6de60`)
- **Scripts in TypeScript:** The verification-media and orphan-reclaim scripts are converted, validated by a transpile diff and a run with every R2 and database variable empty. The R2 audit and preset-media scripts are typed too, and were not run because they upload to R2. (`6f7c781`, `c9b1d13`)
- **Dead script removed:** `seedMonitoringData.js` filled models that were removed and failed on every run. (`fefd021`)
- **Dependencies:** `smtp-server` and its nested vulnerable `nodemailer` are dropped, `js-yaml` is patched (`c83ce4c`). `sharp`, `vitest` and `js-yaml` are updated in the frontend, with the lockfile written by npm 11 because npm 9 and 10 crash on this tree (`48dc407`).
- **Merge:** The lint, pending-fixes and security branches are merged. Conflicts in the auth shell, auth CSS and settings CSS were resolved without dropping either side, since the same commits existed on both. (`62d0d08`)
