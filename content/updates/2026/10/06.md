## Fixes

### Like, save, follow and join races

- **Likes:** Rapid tapping could leave the server opposite to the screen and make counts jump (3, 2, 4). A newer tap aborted the in-flight request in the browser, but the server had usually received it, so like and unlike raced. Every settle refetched the whole post, and that older snapshot overwrote newer optimistic state and dropped loaded comment pages. Realtime counts were dropped while a tap was pending, and nothing ordered events against each other. Likes for posts and comments are now ordered and stale-proof. (`c03709b`)
- **Saves, follows and joins:** `useToggleMutation` (save post, join community, join activity) and `useFollowMutation` debounced taps and, when intent flipped mid-flight, aborted the request and sent the opposite one. Aborting does not un-send, so both reached the server in either order. A new `serialToggle` keeps one request in flight per entity, never aborts it, and sends at most one follow-up per burst, only if the latest intent differs. (`1d94464`)

### Media and gestures

- **Image flicker:** Opening a post image showed it from a synchronously known URL, then swapped it about 50 ms later for a freshly signed URL to the same object, which reloaded the element and faded it out and back in. A URL already on screen is kept, and on a load error the hook re-signs once without showing an error state. Only a second failure shows "Media unavailable". (`d77c19f`)
- **Pull to refresh vs carousels:** At the top of the feed, a sideways swipe on a media carousel drifts a few pixels down, which pull-to-refresh read as a pull, so the page jittered. It now waits 8 px to judge the axis and hands sideways gestures back for their whole length. (`b8d1604`)
- **Double press effect:** The global press scale only stood aside for controls whose own `:active` style changed `transform`, and a frame late. Pill tabs, chips and rows that used opacity, background, colour or a shadow got both effects. `pressFeedback` now reads the stylesheets for every `:active` rule and skips the scale for any control that matches. (`9a18795`)
- **Followers list scroll:** The modal rendered inside `#root` with no scroll lock, so scrolling it scrolled the profile underneath. It is portalled to `<body>`, holds the shared scroll lock and contains overscroll. (`431acad`)

### System bars

During pull-to-refresh the strip was re-sampled mid-pull and picked up the full-width gap surface sliding down, turning the status bar white for about a second. The bars now hold their colours until the pull settles. On Home, while the header and bottom nav are hidden the feed runs under both bars, and the top strip slides with the header on the same transition. (`8723b9b`)

## Improvements

### Landing page and opening screen

- The landing page is rebuilt as an editorial layout: a giant wordmark hero, numbered sections, colour-blocked steps, a 300+ students band, circles as tags, student quotes and a two-card join section. Photography is from Unsplash with credits recorded, and lazy-loaded below the hero. A new floating header has working section links, and cross-page links hand the target over in `sessionStorage` because `SmartBackTracker` drops the hash. (`1690a8b`)
- Mobile menu rows are left-aligned and numbered, and the menu button is one drawn icon that morphs to an X using transform and opacity only. The footer is a full-width ink panel in both themes with icon-only social buttons. (`000dd92`)
- Buttons on the app opening screen are pill-shaped. (`5743e8e`)

### Feed and composer

- Multi-media posts used fixed 16:9 grids with `object-fit: cover`, cropping every photo and ignoring the recorded dimensions. A horizontal carousel is now sized from real dimensions: the row height follows the widest item, every tile shows at its own shape with no bars, and only extreme shapes are cropped. (`97795e7`)
- The composer enforces the existing 6-attachment limit. Pickers cannot be capped, so the first files that fit are kept and a warning says how many were left out. An n/6 counter turns amber at the limit, and the attachment area animates its height on any content change. (`e537094`)
- Comment rows and the Comments heading get more spacing, a faint separator before the date and a brand-tinted count pill. (`35d2945`)

### Navigation

Drawer rows press with a soft tint instead of the app-wide shrink, and hover styles apply only to real pointers. The Settings code is preloaded when the drawer opens, so tapping Settings switches straight away. The shared menu gets a hairline border in both themes. (`af9e281`)

### Communities

The Communities header uses Changa One to match the landing type. Yours and Explore no longer render an empty-state block, and an empty tab shows only its heading. (`5fd5352`)

## Build & Tooling

### Sentry error reporting

- **API:** `instrument.ts` is imported first so http, express and Prisma tracing attach. It is off without a DSN, with `SENTRY_ENABLED=false`, or when `SENTRY_ENVIRONMENT` disagrees with `APP_ENV`. The exception filter reports every 5xx with route, method, status, request id, feature and internal user id, and client responses are unchanged. A scrubber drops cookies, bodies, credential headers, token-like query values and every user field but the id. Releases are named by commit SHA. (`e2ea43a`)
- **Website and app:** The website decides at boot and loads the SDK lazily after first paint (+2.8 KB entry), buffering and replaying early errors, and the CSP allows Sentry ingest. The Capacitor app reports native Android crashes and ANRs. Separate DSN variables stop one env file mixing projects, and host guards keep dev and prod builds off the other's host. Error boundaries, API failures and sign-in and out report through a platform-free facade with the internal user id only. (`eb77cec`)
- **Releases and docs:** Deploy workflows create the `meetifyy-api@<sha>` release, upload the image's source maps, then finalize and record the deploy after the health check. They are skipped unless the GitHub Environment has the Sentry token, org and project, and `docs/sentry.md` records the setup. (`d982975`)
