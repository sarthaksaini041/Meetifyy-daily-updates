## Fixes

### Likes and toggles

- **Likes:** rapid tapping could leave the server opposite to the screen and make counts jump (3 → 2 → 4). A newer tap aborted the request in the browser but the server had usually received it, every settle refetched the whole post and overwrote newer state, and nothing ordered realtime events. Now one request is in flight per post or comment and is never aborted, taps in the meantime coalesce into one follow-up, and responses and events carry a version so anything older than what is shown is dropped. Failures restore the confirmed state. The backend additions are compatible with installed apps. (`c03709b`)
- **Save, follow and join:** the same abort-and-resend race affected saving a post and joining a community or activity, and following. They are now serialised the same way, the first tap is sent immediately instead of after a 280 ms debounce, and a failure restores the state the server actually holds. (`1d94464`)

### Media viewer

Opening a post image showed it, then swapped it about 50 ms later for a freshly signed URL to the same object, so it reloaded and faded out and back in. A URL already on screen is kept, and a failed load re-signs once without showing an error state; only a second failure shows "Media unavailable". (`d77c19f`)

### Press feedback

The app-wide press animation only stepped aside when a control's own pressed style changed `transform`, so controls that used opacity, background, colour or a shadow (pill tabs, chips, rows) got both effects and looked like a double click. It now reads every `:active` rule and skips its scale for any control that has its own. (`9a18795`)

### Mobile

- **Pull-to-refresh and swipes:** at the top of the feed, a sideways swipe on a media carousel drifts a few pixels down, which was read as a pull and made the page jitter. It now waits 8 px to judge the gesture's axis and leaves anything more sideways than down alone. (`b8d1604`)
- **System bars and header:** the status bar turned white for about a second during a pull because the colour sampler picked up the gap surface sliding down. On Home, the top strip now slides with the header instead of fading on a delay. A white band under the blue status strip on a scrolled feed is fixed (Android does not support `background-attachment: fixed`), the hidden header leaves the screen instead of sitting behind the clock, and the rounded edge under the header shows on phones. The drawer has rounded right corners. (`8723b9b`)
- **Followers and following:** scrolling the list, or flinging past its end, scrolled the profile underneath. The modal now locks scrolling and contains overscroll. (`431acad`)

## Improvements

### Landing page and app opening screen

- The website landing page is rebuilt as an editorial layout: a giant wordmark hero, numbered sections, colour-blocked steps, a 300+ students band, student quotes and a two-card join section, with a new floating header, a new footer and a restyled campus request modal. The mobile opening screen is redesigned as a type-only screen with an activity ticker. (`1690a8b`)
- The mobile menu has left-aligned numbered rows and a menu icon that morphs into an X, and the footer is a full-width panel in both themes with icon-only social buttons. (`000dd92`)
- Buttons on the app opening screen are pill-shaped. (`5743e8e`)

### Feed media carousel

Multi-media posts used fixed 16:9 grids that cropped every photo. They are now a horizontal carousel sized from the dimensions recorded at upload, so each tile shows at its own shape and only extreme shapes are cropped. Sizes are final on first paint with no layout shift, scrolling snaps with the next tile peeking, and removing an attachment no longer reloads the remaining tiles. (`97795e7`)

### Composer

Posts are limited to 6 photos or videos, matching the API. Extra files are dropped with an inline warning, a counter turns amber at the limit, the attachment area animates when a tile is removed, and the Image, Video and Poll buttons become icon-only below 380 px. (`e537094`)

### Communities, comments and navigation

- The Communities title uses the same display font as the landing page, and the Yours and Explore tabs no longer show empty-state blocks. (`5fd5352`)
- Comment rows have more spacing, a faint separator before the date and a brand-tinted count pill. (`35d2945`)
- Drawer rows press with a soft tint, and Settings preloads when the drawer opens so tapping it switches straight away. The shared menu gets a hairline border. (`af9e281`)
