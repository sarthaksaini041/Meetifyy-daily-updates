## Fixes

### Status bar and system bars

- **Search and media viewer:** leaving Search with the keyboard up, the status bar kept Search's colour, because the next page's DOM arrived a frame later and was skipped while text entry was active. Sampling now stays allowed for 600 ms after a route change. Closing the media viewer kept its black bars until the 280 ms fade ended. The fading viewer is now ignored and asks for a resample the moment it starts closing. (`158dc97`)
- **Home and Profile:** Profile's status icons flipped between dark and white every time the header hid or returned, Profile's see-through colour carried over to Home, and Home's strip returned pale because it read the page's fallback colour instead of its gradient. All three are fixed. The feed also starts from the real scroll offset, so a scrolled Home no longer shows a blank band for a few frames on arrival. (`bc614be`)
- **Search from Home:** the strip kept Home's blue until the keyboard closed, because the sampler skipped route changes while text entry was active. (`26d1fc8`)
- **Auth pages:** the shell forced light status and navigation icons, which vanished on the white signup page. They are now light only over the phone login page's dark header image. (`5c0b2ee`)
- **Community details:** status icons follow the theme while the details sheet is open, and the cover header takes back over when it is lifted. (`358215a`)

### Notifications

The virtualised list could render zero rows, because its scroll element attached after the list measured. The page now hands the list its scroller, with a window-virtualisation fallback on the website, and loading shows a spinner instead of skeletons. The first page is prefetched while idle, so opening Notifications shows the list at once. (`26d1fc8`)

### Communities and comments

- A freshly uploaded community avatar or cover could load before the loading flag reset and leave the shimmer on until the community was reopened. Loading is now keyed by URL, and the cover's reset watched the wrong field. The community back button is the rounded square Profile uses. (`358215a`)
- The comment composer now clears as the optimistic comment appears and restores the draft if posting fails. The post is no longer refetched after every comment, since the server row replaces the placeholder and realtime covers everyone else. On the backend, the four independent reads run in parallel and the comment and count bump are one batch transaction. (`0315a43`)

### Theme toggle

Presses under 150 ms apart are treated as one. (`4a1331f`)

## Improvements

### Keyboard slides over the page

On Android, the WebView is no longer resized for the soft keyboard. The shell sends one event per transition, so the page never gets a resize or a whole-page restyle while the keyboard moves. Docks rise on the keyboard's own curve and stand on its top edge. The message composer, comment reply dock, sheets, pickers and menus stay above it, the post view no longer moves when its comment composer opens, and the thread in Messages is anchored to the bottom, which also removes an up-down-up flicker. The post composer no longer needs the delayed-keyboard workaround. (`d65d479`)

### Cover editor

Editing a cover opens a drag-to-close bottom sheet (a centred card on wider screens) with a miniature profile preview. Eight CSS-only patterns join the six gradients, and a profile stores the design's CSS, so removing a design later never breaks a profile and older app builds render patterns too. Cover CSS is restricted to gradient functions, colours and lengths, refused on write and not painted on read, so a cover cannot make viewers fetch a URL. A background photo is picked, cropped and shown at once while it uploads with a progress bar. Unsupported or oversized files are refused with a message, a newer choice cancels an upload in flight, and a failure restores the previous cover. (`689c452`)

### Communities

- Community pictures are rounded squares everywhere (directory, community page, campus, search, post badges, sidebars, share sheet, chat previews, notifications and the croppers), and people stay circular. The Communities list is narrower and centred, with a larger avatar, the member count beside the name and a two-line description. A community post whose picture fails to load shows the community's letter on its colour. (`58d309e`)
- Communities, Campus Communities and community search lists are a left-aligned grid of 21 rem cards, with one full-width card per row on phones. Campus discovery uses the same card, and Owner or Joined labels are gone. (`1a4057a`, `358215a`)

### Share and forward

The separate Forward modal is replaced by the share sheet in a forward mode, with the same picker and Send button but no app row or copy link. Each recipient still gets an id derived from one operation id, so a retry is recognised by the server and only goes to the chats that failed. The subject preview card is gone from every share sheet. (`818a890`)

### Posts and profile

- The post header is quieter: the handle, dot and time share the subtitle colour and weight, and the menu uses a two-line icon in a faded colour. (`3378d10`)
- The profile loading skeleton is an outline, not a copy of the page: cover, avatar, bars for name, handle and stats, two button pills and plain post outlines. The signed-in user's own cover, avatar, name and handle still render for real. (`0cbf4fc`)
- Text fields and OTP boxes on the auth pages get a 1 px border (hover darkens it, focus turns it brand, invalid red), and dropdown triggers move from 1.5 px to the same 1 px. (`be839e9`)

### Performance

- **Theme switch:** the circular reveal looks the same but is cheaper, and pressing again mid-reveal reverses it from where it is. On Android a native driver screenshots the window, applies the theme underneath and grows a circular hole, after Chrome re-rasterised a full-screen mask every frame (about 48 fps) following a 180 to 250 ms frozen capture. Bar icons switch as the circle reaches each bar. (`6f3fd6d`)
- **Post composer:** it expands and collapses without re-laying out the feed, using compositor-only clip and transform animations instead of animating grid rows. (`d8a2028`)
- **Left drawer:** the scroll lock walked every element on the frame the drawer started opening. It now follows the drawer one slide later, and the scrim drops its full-screen blur on touch devices. (`6c6cf4d`)
- **Login and signup:** the landing page loads their chunks and background while idle, and at once on hover, touch or focus of an auth link. (`b0ad9df`)
