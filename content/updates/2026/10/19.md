## Fixes

### Search, feed and posts

- **Search 500:** every branch of the ranking `CASE` in the people and community searches was a bound parameter, so Postgres typed it as text and adding the personal score failed. It was production's first Sentry issue after the release: `GET /api/search` returned 500. Each tier is now cast to an integer, with a test that asserts the cast on every branch. (`ad3a16c`)
- **New posts hidden:** the ranked Home feed caches its order for 2 minutes and renews it on every request, so an order built before a post existed could not include it, and opening Home before posting hid new posts for as long as refetches kept coming. Rankings now record when they were built and are rebuilt when a post has been created since. (`58d1e91`)
- **Long posts:** posts were allowed 5,000 characters into a 2,000-wide column, so a long post failed with a 500. See the new limits under Improvements. (`8d5ba14`)

### Chat

- **Older messages:** the browser already keeps the visible message in place when older ones are inserted above, and the list then added the same height again, so the chat snapped to the bottom. It now remembers the top visible message and restores only the difference, and older pages start loading within a screen of the top. (`1eec156`)
- **Can't message:** when a chat can't be messaged, the notice no longer sits partly behind Android's navigation bar (`e25fe75`), the gallery of such a person is empty instead of "Try again" (`efc42a5`), and the chat menu offers only "View profile". (`3f47dcc`)
- **Emoji picker:** wheeling past either end of the list no longer scrolls the page behind it on large screens. (`ffd1a0f`)

### Media viewer

- It opens on the thumbnail the post or chat already showed and swaps to the full image after it decodes. On the app, the scroll lock clipped the body, which threw the feed to the top on every open and brought the hidden header back; it now clips only the root and restores the position. (`a38eac2`)
- The first open no longer goes dark, clear, then dark again. The viewer chunk is fetched while idle and rendered directly. (`754da8f`)
- Dragging a chat viewer down no longer paints the status bar blue; it takes the colour of the page showing through. (`a417917`)

### Signup, dropdowns and prompts

- **Signup survives legal pages:** in the app, the Terms and Privacy links reloaded the site in the same WebView and everything typed in signup was lost. They now open in the system browser, and a 30-minute single-use resume record restores the step and fields if Android kills the app. It never stores the password, code or tokens. After choosing an avatar, the app glides into the finishing screen. (`32d37f5`)
- **Dropdowns and the keyboard:** tapping a dropdown while typing used to drop the keyboard and snap the menu under a resized viewport. First the dropdowns kept the keyboard up, and auth screens on the app stopped re-centring when the keyboard moves (`8868895`). That approach was then replaced: dropdowns now blur the field and wait for the keyboard to finish closing before measuring and opening once, without jumping. (`fb7d481`)
- **Complete your profile:** the cookie banner no longer covers its Save and Later buttons on a short phone, and the current-step pill keeps its colour in dark mode (`d6f79fd`). Later was remembered in session storage, so reopening asked again. It is now stored per account for 10 days. (`0795fe9`)

### App and web

- Voice messages work in the Android app: the manifest never declared `RECORD_AUDIO`, so every recording showed "Microphone access denied". Installed apps need the new APK. (`1484da8`)
- Tapping Home no longer bounces to Crew after a sign-in redirect or reload left the saved page stack stale. (`b54e797`)
- The profile name and counters no longer swap fonts after opening, since the font loads once the app is idle after launch. (`e24c1de`)
- Followers and Following opened from the drawer now go back to the profile, and the cross closes the list. (`1c91a0e`, `15cc331`)
- Sign-in and password-changed emails show the user's local time with its zone, falling back to Indian time. Deploy the backend first, because the API rejects unknown fields. (`896d94e`)

## Improvements

### Push notifications

- **Backend:** a new device table and two notification types (additive migration). Devices belong to the signed-in user and login, and every sign-out or session revoke deletes them. Each notification is written first, then delivered on a push queue with dedupe, retries and dead-token cleanup, so a provider outage never fails the action. It covers web (VAPID) and Android (FCM), messages show no text on the lock screen, and it covers likes, comments, replies, mentions and follows. (`0e25115`)
- **Website and app:** the website subscribes through the existing service worker, a tap opens only a validated in-app route, and nothing shows while the tab is focused. The Android app registers with FCM, with four channels and taps routed through the deep link navigator, including cold starts. Settings gets a push panel with the OS permission and per-category switches, and signing out removes the device. (`74c1f3f`)
- **Asking once:** after first sign-in, the OS or browser permission is requested a single time per device, only if push is available and not already turned on by the account. (`49b8a61`)

### Verification and privacy

- Verification takes one live camera capture, chosen by the user: a selfie or a photo of a government ID. There is no file picker. The server re-encodes each capture with no EXIF data, requires it to be fresh (30 minutes), unused and the right kind, and refuses presigned uploads into the verification folder. (`6ef4130`)
- The privacy policy now says verification is one camera photo, a selfie or a government-issued ID, that it cannot be uploaded from files, and that it is re-processed to remove location and device data. It is published as the next version without needing acknowledgement. (`a053a3c`, `a35c227`)
- The profile shows a college tag only for a verified college, and Settings, Interests has a "Show college and course" switch (on by default). The interests save button sits on a solid bar. (`159da18`, `954d3a3`)

### Limits

Comments are capped at 500 characters and posts at 2,000, enforced by the API with a clear 400 and counted the way Postgres counts them (an emoji is one character). The comment bar shows "N / 500" from 400 characters, and the post composer has a ring that fills as you type, turns red near the limit and blocks Post past it. (`8d5ba14`)

### Communities and Campus

- Community cards sit side by side whenever there is room, with each card at least 16 rem, and phones keep one full-width card per row. (`707d590`) On phones the lists are no longer wrapped in one extra bordered box, and the gap under the Campus header is smaller. (`abba0d3`)
- The sidebar Communities list is fetched once the first screen is up, or when the pointer reaches the header, so it opens in one motion. (`ebb133d`)
- In the app, the community header blurs the cover like Profile instead of going solid, keeps its cover while scrolling and shows the name and member count as the title scrolls away. (`04409ac`, `46fda4f`)
- Posts from a community no longer carry the small community icon on the avatar. (`c919414`)
- Without a verified college email, Campus fills the phone screen above the nav, with larger rows, centred loading, error and empty states, and a request-a-college dialog that is a bottom sheet on phones. (`b84f120`)
- The "Find your college" screen sits on a plain white page on phones, keeps the gradient on large screens, and is centred in its card on desktop. (`17d7bd2`, `861e8e7`, `775b824`)
- The Campus suggested students keep their order for the session, and screens reuse cached data for 5 minutes instead of 30 seconds. The app no longer refetches every query on resume. (`b327eba`)

### Interface

- Comments are laid out like the post above, with the display name, a muted handle that truncates first and the time on one line, and no "Comments 53" header. Post text starts at the avatar edge, and the mobile notifications page no longer scrolls by the top bar's height. (`5817fc1`, `a034ffb`)
- The followers and following modal and the Edit cover sheet are roomier on desktop, and the Create Activity button eases into a held press and ignores repeat taps. (`13d8c2a`)
- The bottom navigation icons grow from 26 px to 28 px. (`0cc1e3f`)
- Instagram stories generate faster: fonts and pictures load in parallel, the last three finished cards are cached and the card is 1200 px wide. Profile stories drop the interest tags, and the share sheet starts clean on reopening. (`c1489bf`)
- Development builds install alongside production as "DEV APP" with their own app id, and app links let each host name its own package. (`0e31684`)

### Performance

- Older chat messages load with one fewer query and round trip per page. (`955a5ca`)
- Opening the app fired 11 to 16 requests in the same second, and on the single production API the feed waited behind them (median 113 ms rose to 418 ms). Badge counts, trending hashtags and online friends now start once the first screen is up. (`c427322`)
- Creating a community takes 4 round trips instead of 6 or 7: the reads run together and cache invalidation is one call. (`50b62e0`)

## Testing

- The notifications cache tests unmount their hooks between tests. A leftover hook could refetch after the next test reset the API mock, which failed one test on a loaded CI runner and blocked the production deploy. (`1c152b3`)

## Build & Tooling

- Each app's local development values now live in `.env.development`, with machine-only overrides in a git-ignored `.env.local`, and the first-year isolation flag is removed from the example env files. (`3dd9f64`)
- `npm run start:dev` finds the dev database again, because Prisma now loads the same env files as the API. (`2ac0c96`)
- Release APK builds read Sentry credentials from a local file, so Android source maps upload to the production Sentry org. A file naming the dev org is refused. (`b4c6e5d`)
- The migration for the college switch is renumbered 22, because migrations 20 and 21 had already landed. (`954d3a3`)
