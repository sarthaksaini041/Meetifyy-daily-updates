## Fixes

### Supabase Data API was open

The public anon key could read and write all tables through Supabase's Data API, including the account-to-handle map behind anonymous Confessions. A migration turns row-level security on, revokes the anon and authenticated grants, and sets no default grants for new tables. Confessions requests also no longer log the account, IP, device or body, and posting is serialised per profile so a double tap cannot post twice. The minimum confession length is 15 characters. (`14b8805`)

### Public repository hygiene

- **Azure setup:** The Azure setup reference lists full subscription and tenant IDs and the Microsoft account emails behind each environment, which do not belong in a public repository. It is removed from the index with the local copy kept, its `.gitignore` exception is dropped, and the README no longer links to it. Earlier commits still contain the file. (`cdd8485`)
- **Contact addresses:** Every place that published a Gmail address now uses `support@meetifyy.app` (account help, legal documents, support Reply-To) or `contact@meetifyy.app` (general and partnership enquiries, new About section). A migration publishes silent new versions of the affected legal documents with only the address replaced, and is a no-op when re-run. (`d030f2d`)
- **Stale env override:** The About page still showed the old address because `VITE_SUPPORT_EMAIL` was set in the local and Vercel environments. Both addresses are public brand constants, so config defines them directly and the `VITE_` variables are dropped. (`f67eafa`)

### System bars

Closing or dragging the media viewer left `#root` inert, so the edge sampler read the body gradient and painted both bars blue. The bars also re-sample during a scroll, every 90 ms. Campus draws its red banner under a transparent status bar, and Messages on phones in light theme paints a plain white gradient. (`6a44748`)

### Chat layout

- **Message spacing:** Every row carried its own margin, and a flex column never collapses them, so text sat 4.8 px from its neighbour while cards and media sat 7 to 15 px. The thread's gap and four tokens now set every distance. Same-author messages close up to 2.4 px and an author change keeps 8 px. (`63b162e`)
- **Reply bar:** It floated above the composer and took no room, hiding the last messages when scrolled to the bottom. The composer now measures it and reserves exactly its height. The label reads "Replying to Aarav". (`8e5e9bf`)

### Other fixes

- **Campus pills:** On the Campus hub only the college name row was sticky, so the shortcut pills scrolled away. The whole banner is sticky now. (`95e5861`)
- **Spacing:** The profile card and its posts are exactly 8 px apart at every width. The search page is pure black on phones with 8 px between every result. (`ed3c183`, `14c0303`)

## Improvements

### Email changes need proof

- **API:** Changing the sign-in email, changing the college email and removing it need a fresh, single-use reauth grant: the password, or a code to the current address for accounts without one. The grant is bound to the user, purpose, session and the address its code went to. Each email may change once every 30 days, tracked in `EmailChangeEvent` and enforced under a row lock against the database clock. Removal is never blocked but restarts the college cooldown, and admin revoke and reset start none. (`dbb4252`)
- **Direct bypass closed:** A trigger on `auth.users` refuses Supabase's own self-service email change and any auth email write without a live intent, closing the direct `PUT /auth/v1/user` bypass. Interrupted changes are reconciled from Supabase and never reverted once complete, and the notice to the old address is idempotent and retried. Installed apps keep the legacy password bodies, which spend the password budget in the service. See `docs/email-change-security.md`. (`dbb4252`)
- **UI:** Settings and Campus ask for the password or an emailed code in a shared `ReauthModal` before any change or removal. An expired grant is renewed with one prompt and the request retried, and cooldown rows show the server's "change again on" date in local time. (`82ee798`)

### Confession reactions

- **Reactions:** Five reactions (Love, Funny, Sad, Surprised, Relatable) replace Relate. Existing relates become Relatable, and the old routes keep working for installed apps. Each change is one SQL statement. Reaction totals go live to a campus-scoped socket room, and `POST /api/confessions/sync` lets a reopened feed catch up in one request. (`a366b04`)
- **Sharing:** Confessions can be shared into chats as an id-only card, read back under the reader's campus access, with a deep link. A confession the reader may not see shows as an italic "This confession is no longer available", like an unsent message. (`a3c00ca`, `0ef2e0e`)
- **UI:** Once a confession has reactions the card shows only their summary, which opens a counts modal to react, change or take yours back. Taps are coalesced into one request per burst. Names get pixel avatars and a privacy hint. (`a3c00ca`, `14b8805`)

### Media limits

Messages take up to 15 MB a video and 5 MB an image, posts 25 MB a video and 5 MB an image, and voice notes 15 MB, each file on its own with a 413 on refusal. The presigned PUT signs the declared size, so R2 refuses any other length, and confirm and post creation re-measure from storage. Chat attachments from outside a chat upload are measured at send time, so a post video can no longer ride into a chat. (`c26c326`)

On the client, the video viewer's controls auto-hide, side taps reveal them on touchscreens, double-tap seeking chains, and fullscreen works in the app through a native plugin. Chat videos show their poster frame and real shape from the moment they are sent. Voice notes stop at 5 minutes with a countdown pill and a recording is kept through failed uploads until sent or deleted. (`d324439`)

### Native page transitions

The app animates opening and closing pages natively. `PageTransitionPlugin` screenshots the window with `PixelCopy`, draws it in the decor overlay and moves it with one animator, so the WebView itself never moves or re-rasters. A slide effect covers Settings, Search, notifications, chats and the drawer's communities, and an X-style centre effect opens posts, profiles, communities, search results, Campus people and activities, and the Directory. The history remembers the effect so Back replays it. A post's four action buttons dissolve before the rest on close. On the website these stay plain navigations. (`ec9d848`, `39abe54`)

### Directory

The directory returns `isCampusRep` for each person, false for a blocked row, and the campus representative badge sits on the lower-right edge of the person's avatar, ringed in the card colour. The name line holds only the name and "(You)", and a long name ends in an ellipsis with the full name as a title. (`611aaba`, `adaa9e3`)

### Chat bubbles

Bubbles are 22 px on all four corners with no tail, and the reply quote derives a concentric radius from the same token. Below 480 px a bubble may use the whole row. "Show more" is solid bold white on sent bubbles. (`b8e2f5d`)
